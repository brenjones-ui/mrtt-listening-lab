# MRTT Listening Lab

Music Ready to Teach Listening Lab: a fast, classroom-ready listening activity builder for secondary music teachers.

## Pilot principles

- Open pilot: no login or payment gate.
- No pupil or class data capture.
- MRTT Audio Repository Index remains the editorial source of truth.
- Questions must be grounded in an asset's `Knowledge / Skill` field, not generated from a concept label alone.
- Rights/review status is enforced before any asset is exposed to the pilot.
- Teacher flow: **Choose -> Build -> Ready -> Go Live -> Check -> Support / Apply / Stretch**.

Development begins on feature branches; `main` remains the stable baseline.
